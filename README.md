PROJETO-DO-AGRINHO

O site "Agrinho Soluções 2026 - Agro Sustentável" foi desenvolvido com o objetivo de mostrar como a tecnologia e a sustentabilidade podem trabalhar juntas para fortalecer a agricultura e preservar o meio ambiente.

O projeto é baseado no tema "Agro Forte, Futuro Sustentável", destacando práticas agrícolas modernas que aumentam a produtividade ao mesmo tempo em que reduzem impactos ambientais.

Principais Funcionalidades

🌾 Eco-Ações Apresenta exemplos de tecnologias e práticas sustentáveis utilizadas no campo, como agricultura de precisão, drones, biotecnologia, rotação de culturas, preservação de nascentes e uso de energia limpa.

📊 Painel de Impacto Ambiental Mostra indicadores simulados de:

Água economizada; Solo protegido; Redução de emissões de CO₂.

Essas métricas demonstram como a tecnologia pode contribuir para uma produção agrícola mais sustentável.

🚜 Simulador de Plantio Permite selecionar diferentes culturas agrícolas e simular a contagem de sementes. Durante a simulação, o sistema calcula informações relacionadas à eficiência ecológica e apresenta recomendações sustentáveis para cada cultura.

🧠 Quiz Educativo Testa os conhecimentos do usuário sobre agricultura sustentável, tecnologia no campo e preservação ambiental por meio de perguntas interativas.

Objetivo do Projeto

O principal objetivo do site é conscientizar as pessoas sobre a importância de unir desenvolvimento agrícola e preservação ambiental. O projeto mostra que é possível produzir alimentos de forma eficiente utilizando tecnologias que ajudam a economizar recursos naturais e proteger o planeta para as futuras gerações.

Tecnologias Utilizadas HTML5 para a estrutura do site;

CSS3 para o design e a identidade visual;

JavaScript para as funcionalidades interativas, como o simulador e o quiz.
